# Demonstration 07: Easy Mode — Senior-Friendly Front Desk Operations

## Objective
Walk through the dedicated Easy Mode interface tailored for older hotel staff and nontechnical front desk team members.

## Walkthrough Steps
1. **Activate Easy Mode**: Toggle via header or /easy-mode; observe high-contrast, 18px+ typography and large 52px+ touch targets.
2. **Arrivals Workflow**: Review today's arriving guests; complete 1-click check-in with automatic room occupancy update.
3. **Departures Workflow**: Process guest check-out; trigger automatic housekeeping task creation.
4. **Room Status Board**: Toggle room Clean/Dirty with a single tap.
5. **Text Resizer**: Switch between Standard, Large, and Extra-Large typography instantly.

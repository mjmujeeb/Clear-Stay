# ClearStay 3.0 — Product Walkthrough Demonstrations & Verification Media

This directory contains the complete multimedia suite and technical scripts for the **ClearStay 3.0** enterprise hotel distribution platform, prepared for portfolio demonstration for Temairazu, Inc. (TEMAIRAZU).

## Directory Structure

- ideos/: Playable high-definition MP4 demonstration videos for all 8 core workflows.
- screenshots/: High-resolution visual snapshots of each workflow.
- scripts/: Markdown walkthrough scripts with technical context and step-by-step procedures.
